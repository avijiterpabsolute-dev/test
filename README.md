# Test Repository

A simple Node.js test repository demonstrating basic testing functionality with Mocha and Chai.

## Features

- Simple calculator module with basic arithmetic operations
- Comprehensive test suite using Mocha and Chai
- Error handling and edge case testing

## Installation

```bash
npm install
```

## Running Tests

```bash
# Run all tests
npm test

# Run tests in watch mode
npm run test:watch
```

## Project Structure

- `index.js` - Main calculator module
- `test/calculator.test.js` - Test cases for calculator functions
- `package.json` - Project configuration and dependencies
